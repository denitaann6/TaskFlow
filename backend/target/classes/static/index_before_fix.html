Phase 4: Advanced Algorithms & Optimization

Syllabus Capstone Techniques: Greedy Heuristic Selection, Dynamic Programming (0/1 Knapsack), and Backtracking Dependency Planning.

1. Greedy Algorithm: Priority-Density Pending Task Selection

Greedily selects pending tasks ordered by priority-to-effort density ratio within the specified time limit.

Click "Run Greedy Selection" to compute priority-density task scheduling.

2. Dynamic Programming: 0/1 Knapsack Task Allocation

Tabulates all subproblems to find the globally optimal subset of tasks maximizing total sample benefit within the time limit.

Click "Compute Optimal Allocation (DP)" to solve 0/1 Knapsack task scheduling.

3. Backtracking: Dependency Constraint Planning

Explores the state-space tree of task orders, ensuring every prerequisite task finishes before its dependents, while detecting circular cycles.

Click "Generate Valid Schedules (Backtracking)" to compute constraint-satisfying execution sequences.
