SECTION TWO

Dynamic Programming: 0/1 Knapsack Optimal Allocation

Constructs a 2D state table (DP[i][w]) to guarantee the mathematically optimal task subset within available hours

Globally Optimal Tabulation (O(N × W))
Recurrence Relation: DP[i][w] = max(DP[i-1][w], DP[i-1][w - duration[i]] + benefit[i]). Unlike the Greedy heuristic which can miss the global optimum in non-fractional knapsack problems, DP guarantees finding the optimal subset through bottom-up subproblem memoization.

SECTION THREE

Backtracking: Dependency Constraint Planner

Explores execution schedules level-by-level, verifying prerequisites and pruning invalid branches

State Space Tree Search with Pruning
Pruning Rule: A directed edge $(A \to B)$ means Task A must finish before Task B begins ($index(A) < index(B)$). When the recursive search places candidates in sequence, if a candidate has unmet prerequisites, that branch is immediately pruned, eliminating fruitless permutation sub-trees.
